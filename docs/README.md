# tui-design documentation

`tui-design` is an agent skill: a folder of instructions, references and scripts that a coding agent loads when you
ask it to design, build or review a terminal UI. These pages are for the people who install it, read its output or
work on it. The agent itself reads only `skills/tui-design/` (start at its [SKILL.md](../skills/tui-design/SKILL.md)).

![The HTML gallery the skill builds for a design: selectors, keys and export buttons around one rendered frame](img/gallery.png)

## Use it

- [Getting started](getting-started.md): install, first prompts, what the agent does with them.
- [Concepts](concepts.md): terminal-honest frames, the cell grid, capability profiles, perception vs judgment,
  tokens instead of colors.

## Features

| Page | What it covers |
|---|---|
| [Mockups](features/mockups.md) | the `.mock` format, building frames with `mockkit.py`, `render_mockup.py --check` |
| [Gallery](features/gallery.md) | the HTML page of frames: selectors, keys, side by side, export, opening and sharing it |
| [Host verification](features/host-verification.md) | test card, key probe and `play_mock.py` for plugins and popups |
| [Audit](features/audit.md) | live capture, the screenshot pipeline, sampled colors, `compare.py` |
| [Themes](features/themes.md) | 25 theme variants, preview, contrast at truecolor and 16 colors, exporters |
| [Starters](features/starters.md) | the five framework proto-starters, frame mode and capture |
