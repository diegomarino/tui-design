# K. Chat / agent session

Part of [layout-archetypes.md](../layout-archetypes.md) (rules L1–L14 in §2). Sketch rows: `H` header, `M` message line, `K` keybar. § numbers on the **Exemplars** line are sections of [exemplars.md](../exemplars.md).

**Use** when the user converses with a responder that streams text and acts on their behalf (AI coding agents, chat clients, assistant REPLs): turns accumulate, the newest matters most, and the user writes the next message while reading. **Avoid** for feeds nobody answers (E), a single question answered in a script (one-shot CLI: print, exit), or a "conversation" that is really a fixed set of inputs (F).

```text
H  quill ~/src/payments · main                                       ctx 41%
          ↑ 5 earlier lines                          <- scroll cue, fg.faint
 you      Also cover the jitter path.                <- user turn on bg.surface
 quill    Adding TestRetryJitter with a seeded so…   <- role word, accent.primary bold
          ✓ edit  internal/webhook/retry_test.go                       +31
          ⠹ run   go test ./internal/webhook                           12s
╭──────────────────────────────────────────────────────────────────────────╮
│ ❯ █ type to queue a message                                              │
╰──────────────────────────────────────────────────────────────────────────╯
M  ⠹ working 41s · 2 tools so far                               ↓ following
K  esc interrupt  enter queue  pgup read history         f1 help  ctrl+d quit
```
- **Regions**: header (project, branch, model or mode, context use) · history (a role column of ~7 cells, then text capped at ~76 cells, L7) · live tail (the turn in progress: streaming text and running tools; the only part that animates) · input box (the one bordered, focused region) · status line (state, elapsed time, follow state) · keybar. At ≥ 110 cols an optional sidebar: changed files, plan, context meter, permissions (`session--normal--120x30`).
- **Turns**: every turn opens with a role **word** in the role column (`you`, the assistant's name, `error`), never color alone, so 16 colors, `NO_COLOR` and screen readers keep the roles (the `bg.surface` band under user turns vanishes at 16 colors; the word stays). Tool calls are one-line receipts: status glyph, verb, target, result right-aligned in `fg.faint` (`status.error` when it failed); full output on demand (a transcript view, or Enter on a receipt), never dumped inline.
- **Focus**: the input owns focus and every printable key (as in F). History is read with non-printable keys (PgUp/PgDn, Ctrl+Home/End) or in a separate transcript mode where `/`, `n`, `j`/`k` work because the input is not focused (Claude Code: `Ctrl+O`). `/` and `@` at the start of the input open a palette above it (G).
- **Keys** (Claude Code "Interactive mode"): Enter sends; a newline needs a key every terminal delivers: `Ctrl+J` "works in any terminal", `\`+Enter, while Shift+Enter is native only in some terminals; Esc stops the running turn and "keeps the work done so far"; ↑ on the first input row recalls history; Ctrl+C clears the input, a second press exits ([cli-contract.md](../cli-contract.md) CC3).
- **Responsive** (`derived:`): 60 cols = role word on its own row above the text, receipts drop the verb, results stay; 80x24 = one column, input 1 row growing to 5 (`session--normal--80x24`); 120x30 = sidebar 36 cols (`session--normal--120x30`); 170x40 = sidebar plus a diff or output pane for the selected receipt. Minimum ≈ 40x10 (3 history rows, 3-row input, status, footer); below it the too-small screen ([§2.2](../layout-archetypes.md#22-the-too-small-screen)).
- **States**: empty = what to ask, the `/` `@` `!` entry points, recent sessions with ages, input focused (`session--empty--80x24`); busy = streaming tail, spinner only on the live row, elapsed time, input still live and **queues** (`session--busy--80x24`); awaiting approval = the exact action (command, diff, path), numbered choices with the safe one first (`1 yes  2 yes, always for go test  3 no`), nothing else on screen changes until answered (rule K7); error = an `error` turn with what, why and next (`✗ rate limited (429) · retry in 20s · esc stop`), history kept; disconnected = header chip and the elapsed wait ([interaction.md](../interaction.md) §8.1).
- **Pitfalls**: re-rendering the whole transcript per token (flicker, FR-02); auto-scroll that yanks the reader back to the bottom; a spinner in the header *and* on the row (two signals, LH-12); an input that loses typed text when a turn finishes; approvals that accept on a single printable key while the user is typing; full tool output inline.
- **Exemplars**: Claude Code, Gemini CLI, Copilot CLI (Ink), Codex CLI (Ratatui; [frameworks/choosing.md](../frameworks/choosing.md) §1).
