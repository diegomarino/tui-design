# Changelog

Releases are tagged `vX.Y.Z`; pin one by adding `#vX.Y.Z` to the install command in the README.
The skills CLI itself updates on any change under `skills/tui-design/`, so this file is for people.

## 0.1.0 — first public release

- **Skill** (`skills/tui-design/`): four branches (quick review, design, build, audit) plus color, for full-screen
  TUIs, inline pickers, one-shot CLIs and plugins inside a host.
  - `.mock` frame format with a linter (`render_mockup.py --check`), a Python mock builder (`mockkit.py`), PNG/SVG
    rendering and HTML galleries.
  - Host capability profiles: `test_card.py`, `key_probe.py`, `play_mock.py` and the `#! caps:` line.
  - Audits with perception separate from judgment: live capture (`capture_tui.sh`, `ansi_grid.py`), a screenshot
    pipeline with pixel-sampled colors, and a 135-check rubric.
  - 25 theme variants of 10 schemes on 44 semantic tokens, contrast checks at truecolor and 16 colors, exporters
    for Textual, Ink, Lip Gloss, Ratatui, gum and CSS.
  - Proto-starters for Ink, Textual, Bubble Tea, Ratatui and gum; references on archetypes, interaction,
    lifecycle, the shell contract, terminal capabilities, glyphs, accessibility and visual craft, with a worked
    example; `references/tools.md` lists every script.
- **Gallery**: the reference mockups, in all 25 themes, are published at
  <https://diegomarino.github.io/tui-design/> (`.github/workflows/pages.yml`).
- **Docs** (`docs/`): getting started, concepts, one page per feature, evals and architecture, with screenshots
  regenerated by `tools/make_screenshots.py`; the worked example's frames and generator in `docs/showcase/`.
- **Evals** (`evals/`): behavior harness (24 cases, skill vs baseline, program / executed / judge / vision
  assertions, isolation and secret redaction), trigger evals, export to Langfuse and Phoenix, an experiment
  ledger, and the published scores ([docs/evals.md](docs/evals.md)).
- **Tests** (`tests/`): unit tests for the skill's scripts and the eval harness.
